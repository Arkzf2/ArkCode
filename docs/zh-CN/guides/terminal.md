# 在终端中工作

[English](../../en/guides/terminal.md) | 简体中文 | [文档首页](../README.md)

## 提交、纠正和排队

空闲时按 Enter 提交任务。任务运行期间按 Enter 发送 steer，补充或纠正当前任务；按 Tab 将新任务加入 follow-up 队列，当前任务结束后继续处理。Shift+Left 可编辑尚未消费的队列输入。

输入 `@` 搜索工作区文件和已启用 Skills。选择文件会插入文件提及，路径含空格时保留引号。选择 Skill 会插入 `@skill:name`，详见[Skills 指南](skills.md)。

需要自己运行 shell 命令时，输入 `!` 后接命令。命令使用当前会话选定的 shell，并经过对应审批。它不会把终端变成交互式 shell。

## 查看工具和历史

工具输出默认显示简短预览。点击 `+N lines` 展开当前结果，点击 `Show less` 收起。Ctrl+T 控制全部工具详情和模型提供的推理内容。write 和 edit 显示文件变更预览；较大的 write 可能只显示执行结果。

使用滚轮或 PgUp/PgDn 浏览历史，End 返回最新内容。Ctrl+L 清理视图，不删除历史。底栏显示模型、推理等级、目录、权限和 Git 分支；上下文行显示已用 token、窗口和百分比。`~` 表示估算，`?` 表示尚未取得新用量。

## 复制与编辑

拖动鼠标选择转录文字，松开后复制。已有选区时 Ctrl+C 复制，Esc 清除选区。Shift+拖动可使用终端自身选择功能。Ctrl+O 或 `/copy` 复制最近完整回答。

Ctrl+R 搜索提示历史，Ctrl+G 使用 `VISUAL` 或 `EDITOR` 编辑草稿。空输入框双 Esc 编辑上一条提示并创建分支，不回滚文件。

## 中断与退出

Esc 中断当前任务，在面板中则返回上一级。没有选区时，Ctrl+C 在运行期间中断，空闲时退出。Ctrl+D 在空输入框退出。`/exit` 停止本终端拥有的全部会话及受管进程。

中断保留已经完成的工具效果。强制结束宿主也不保证外部进程或 MCP 服务端操作已经停止，异常恢复见[故障排查](../troubleshooting.md)。完整按键及 slash 语法见[交互命令参考](../reference/commands.md)。
