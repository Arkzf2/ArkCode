设计依据

采用 Codex 的状态色、状态栏角色色与 diff 增删语义；采用 Kimi 的用户角色色、强调文字与独立组件 token。全部方案保持黑色终端，增删仍用绿与红，普通正文保持中性。以上配色为 ArkCode 自定义方案。

源码依据见 Codex styles、status line、diff renderer、Kimi theme schema。本次以本地 checkout 源码为准。

底部依次为模型、推理等级、目录、权限、分支、上下文用量。配色和视觉方案独立切换，保留当前流程进度。像素柔光与静态颗粒只在标记、边缘和留白出现；正文区域不加滤镜。浏览器的颗粒与柔光不作为原生 TUI 的实现要求。
